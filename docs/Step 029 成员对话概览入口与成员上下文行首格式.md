# Step 029 成员对话概览入口与成员上下文行首格式

主对话用 `call_member` 派出几条成员对话以后，「本对话现在有哪些成员、各自在干什么」此前只能靠
模型自己写进回答里，人看不到。这一批把这个信息放到对话本身上：会话头部多一个
「[图标] N个成员对话」入口，悬停列出身份/状态/成员，点开是完整详情；同时把注入给模型的
`[成员上下文]` 快照改成以身份和工作区开头，几条并行会话一眼能分清。

## 1. 成员上下文：身份和工作区放到行首

`[成员上下文]` 快照（`agent/pre-step` 注入）和 `[成员调度]` 推送共用同一个行渲染器。以前一行以
会话 id 开头，身份和工作区埋在括号里；现在身份、工作区在最前，会话 id 降为后面的定位信息：

```text
# 以前
- c1（B 10.66.66.2，工作区 dsh-mesh，进行中，第 2 轮）身份：内核开发4；工作范围：kernel/**
- 自身（会话 session-a）：身份：网关；工作范围：成员发现；保持目标：关闭（只对主对话生效）…

# 现在
- 身份：内核开发4；工作区：dsh-mesh；会话：c1（B 10.66.66.2，进行中，第 2 轮）；工作范围：kernel/**
- 身份：网关（自身，会话 session-a）；工作范围：成员发现；保持目标：关闭（只对主对话生效）…
```

- 同一条规则也用在自身行：身份在最前，`（自身，会话 <id>）` 只是说明这是哪条会话。
- 其余字段与顺序不变：工作范围、显式 `compressPercent`、`note`（备注）仍在行尾；缺失的身份
  仍写 `未设置`，聚合提示（`还有成员会话没有身份/工作范围：…`）不变。
- `status_member` / `wait_member` 的表格与清单输出不变：它们本来就是给模型逐项查看的。

## 2. 会话面板的「成员列表」区

> **后续更新**：这个入口最初放在会话头部工具区（悬停列表 + 点击详情）。现在挪到会话右侧面板，
> 和「环境」「成员列表」「子智能体」并排：标题「成员列表」、标题右侧「N 个 · 进行中/全部空闲」、
> 每行一条成员对话（身份 + 状态 + 成员 + 工作区），点一行看该成员详情，超过 5 行折叠；没有成员
> 对话时整区不显示。下面关于数据与刷新的描述仍然有效，头部入口已移除。

客户端注册在 `conversation.session.header.utilities`（会话头右侧工具区，宿主自己的按钮之前），
只出现在有会话的界面里；这条会话没有成员对话时组件渲染 `null`，普通对话的头部保持原样。

### 数据

浏览器不读任务文件，只调宿主新增的只读接口：

```text
GET /api/dsh-mesh/member-conversations?session=<主对话 session id>
→ { ok, total, running, conversations: [ ... ] }
```

`conversations` 每项一行，由 `src/lib/member-ui.mjs` 从任务表（`member-tasks/*.json`）和
`member-scopes.json` 合成，字段固定：

| 字段 | 含义 |
| --- | --- |
| `conversationId` | 成员会话 id（继续投递用的凭据） |
| `member` / `memberIp` / `memberName` | 成员名、VPN 地址、快照里记的成员名 |
| `memberLabel` | 界面上的短标签：IPv4 取最后一段（`10.66.66.3` → `3`），否则退回成员名 |
| `workspace` | 工作区名称 |
| `identity` / `scope` | 身份、工作范围（`member-scopes.json` 优先，回退任务快照；没有就是 `null`） |
| `status` / `statusLabel` | 任务状态与中文标签：running/starting=进行中，completed=空闲，failed/interrupted=异常中止 |
| `turns` / `createdAt` / `updatedAt` / `lastSentAt` | 轮次与时间 |
| `note` / `compressPercent` | 只存本机的备注、显式压缩阈值（未设置为 `null`） |
| `prompt` | 最初任务的前 280 字符 |

只列**本条主对话**（`originSessionId`）跟踪、未归档的会话，顺序与任务表一致（最早在前）。
未注册任务表或会话 id 为空时返回空列表，不报错。

### 交互

- 触发器：`[图标] N个成员对话`，有进行中的会话时图标旁多一个呼吸点。
- 悬停：列出每条会话的 `身份（未设置身份）`、状态标签、`成员 3 · 工作区 xxx`。
- 点击某一行：只弹这一条成员会话的详情；点击入口本身或列表底部的「查看全部」才列出所有会话。
- 详情弹窗，每条会话一块：身份、工作区、所属成员（短标签 + 成员名 + IP）、工作范围、状态、
  轮次、会话 id、压缩阈值、备注、最近更新、最初任务；右上「刷新」立即重读。
- 刷新：打开页面后每 10 秒读一次（页面隐藏时跳过），打开详情时再强制读一次；读取失败保留上一次
  成功的列表，不会让入口闪没或显示假状态。
